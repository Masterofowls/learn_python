# Learner / tutor notes (Cursor)

When helping in this repo:

1. Read `docs/CURRICULUM.md` and `docs/PROGRESS.md` first.
2. Teach only the **Current** lesson unless the learner asks to review a past one.
3. Format: Theory → Test → task in `lessonN.py` → check quiz + code.
4. Honor stage locks: no NumPy/pandas/pytest until Stage 2 is done; no FastAPI/Django until Stage 3 is done.
5. After completing a lesson review, remind the learner (or update) `docs/PROGRESS.md` and `docs/ACTIVITY_LOG.md`.
6. Prefer the learner writing code; do not skip their practice by implementing the whole task for them unless they ask and mode allows it.
