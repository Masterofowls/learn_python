# JavaScript — how to learn

Same loop as Python. See also [../HOW_TO_LEARN.md](../HOW_TO_LEARN.md).

**Quizzes are skipped for now** (Theory → task → review only).

## Run a lesson

```bash
node js/lesson1.js
```

Or:

```bash
cd js
node lesson1.js
```

## File conventions

| Kind | Pattern |
|------|---------|
| Lesson | `js/lessonN.js` |
| Helpers | `js/helpers.js` (when needed) |
| Package (from L22) | `js/package.json` |

Prefer:

```js
function main() {
  // ...
}

main();
```

(or `export` + separate run when modules start in L10).
